## Efficient Neural HFT (Market State Forecasting)

* **Architecture:** Utilized a "Hive Mind" Ensemble of Deep Residual GRUs and LSTMs optimized with Squeeze-and-Excitation blocks.
* **Model Compression:** Engineered an INT8 Dynamic Quantization pipeline, reducing the memory footprint by 75%.
* **Robustness:** Integrated MLOps workflows and custom financial loss functions (Huber, Pinball) for production-grade performance.
